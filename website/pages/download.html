Mac

Apple silicon and Intel

Download for Mac

{{mac.file}}{{mac.size}}

  1. Open the .dmg file and drag Broadcast Empire to Applications.
  2. Open the game from Applications. macOS will say it cannot check it.
  3. Open System Settings, go to Privacy & Security, scroll down and choose “Open Anyway”. You do this once.

If macOS says the app is damaged, open Terminal, run this line once, and open the game again:

xattr -cr "/Applications/Broadcast Empire.app"

Windows

64-bit

Download for Windows

{{windows.file}}{{windows.size}}

  1. Run the downloaded Setup file.
  2. When Windows shows “Windows protected your PC”, choose “More info” and then “Run anyway”.
  3. The game is installed and opens. Later you find it in the Start menu.

Linux

64-bit, AppImage

Download for Linux

{{linux.file}}{{linux.size}}

  1. Make the file executable: in your file manager under Properties, or in a terminal with the line below.
  2. Open it. There is nothing to install.
chmod +x "{{linux.file}}"

Some systems need the package libfuse2 to run an AppImage. If the game still does not start, run it from a terminal with --no-sandbox after its name.

Good to know

A newer version
Install it over the old one. Your saved games stay where they are, and a save from an older version still opens.
Saved games
Each save is a file in the game's own folder. Settings on the home screen shows the folder and opens it.
  • Mac: ~/Library/Application Support/Broadcast Empire/saves
  • Windows: %APPDATA%\Broadcast Empire\saves
  • Linux: ~/.config/Broadcast Empire/saves
Which version you have
It is on the home screen and at the bottom of Settings. Name it when you report a problem.
What changed
The changelog has every version, with what is known not to work yet.
